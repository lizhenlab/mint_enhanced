# 评测与质检

“评测与质检”提供两条主路径：**数据集评测**回答选定输入上算法的误差、覆盖和失败情况；**逐帧质检**帮助定位已有结果中需要人工查看的片段。两者共用已保存的比较与几何结果，但不互相替代。

## 选择入口

| 目的 | 入口 | 需要的输入 | 主要产物 |
|---|---|---|---|
| 对多个输入进行定量比较 | 数据集评测 | 视频或 Episode、算法设置、每个输入的显式参考标注 | 持久批次、各输入比较、误差与覆盖报告 |
| 检查一个已有比较的局部问题 | 逐帧质检 | 已发布的预测结果；参考结果可选 | 复核候选片段、曲线、误差分解、独立二维修正 |
| 查看所选比较的整体指标 | 所选比较的指标 | 当前已打开或在质检中读取的比较 | 该比较现有的指标视图 |
| 对固定协议比较检查点或资源参数 | 更多 → 检查点回归 / 性能 | 固定输入与参考协议、候选检查点或卡数设置 | 回归与性能记录 |
| 使用专项公开基准工具 | 更多 → 公开基准 | 该工具要求的数据和模型资产 | 对应专项报告 |

“所选比较的指标”是上下文入口，有已发布结果时才显示，不创建新评测。回归与公开基准收在“更多工具”中，避免与日常数据集评测、逐帧检查混在同一层。

## 数据集评测：先声明参考，再检查并提交

数据集评测沿用三个步骤：核对输入清单、选择算法、预检与提交。默认处理全片并保留源帧率，参考策略固定为每个输入必须有 GT。视角、抽帧、截取范围和相机内参放在高级设置中；需要修改时再展开。

预检逐输入检查视频范围、参考、算法依赖与内参条件，展示可处理帧数和警告。预检不启动推理；显式提交后才生成后台批次。修改输入或协议后需要重新预检。完整操作与取消恢复规则见 [批量比较与数据集评测](batch-comparison.md)。

结果先展示完成、失败、覆盖及核心误差，完整指标表按需展开。阅读结果时应同时看误差和有效计数：较低误差可能只来自少量可评分帧，不能忽略部分结果、失败输入或参考缺失。GT 的监督范围也可能不同，例如只标注一只手、只有相机轨迹或采用跟踪骨架参考。

参考标注和算法已知内参分别声明。提供 GT 用于评分，不会自动意味着把 GT 的相机内参交给预测算法。高级设置中明确提供内参后，各算法仍按其自身能力使用；MINT 保持 FoV 预测，ACE K-free 保持内参预测，ACE K-given 必须有内参，HaWoR 在提供标定时使用标定。

平台统一几何评测用于在已声明输入、帧映射、坐标和参考条件下比较算法。它不等于自动复现所有数据集论文的官方 benchmark 协议；需要对外报告官方成绩时，还要核对该数据集要求的划分、指标、监督与对齐方式。

## 逐帧质检：一个来源，三个查看方式

先在顶部选择比较并读取结果，再选择预测和参考。来源摘要说明当前比较、预测与参考角色。三个页签共用这份选择，避免在不同区域重复选择后产生错配。

- **问题片段**：查看样本帧数、复核候选数量、缺失预测输出帧及参考角色，按片段定位视频。阈值和逐帧曲线放在高级区域；曲线一次显示一个指标，避免不同单位被画成难以解释的同一刻度。
- **误差明细**：默认比较总体、左手、右手；深度分组和逐关节细节展开后查看。使用声明 GT 时解释为参考误差，使用另一算法结果时解释为算法差异。
- **二维修正**：编辑选中帧的二维关节点、可见性或左右手标签，保存独立的人工修正版本。修正不会覆盖原始推理几何。

这些检查读取已发布的几何结果，不需要重新运行核心推理模型。切换页签、展开阈值或曲线也不提交新的 GPU 推理任务；重新分析只依据所选结果计算诊断数据。

## 怎样解释“问题”

缺失预测输出、无可见手部几何、存在性判断偏低、关节差异超过阈值、腕部加速度突变分别记录，均是**人工复核候选**。缺失输出按完整输入时间线计算；无可见几何也可能对应画面中没有手，运动突变可能是真实动作，不能直接当作算法错误标签。

没有 GT 时可以比较运动平滑性、几何可见情况和算法差异，不能据此宣称绝对精度。存在显式参考时也应查看参考角色、有效帧和监督范围，不能仅凭“有参考”就将其当作全面可靠的真值。

二维修正只提供当前图像网格上的二维信息，**不会自动成为三维关节点或 MANO 真值**。需要三维训练监督时，仍需单独的合法标注来源、坐标标定与数据版本流程。复核候选也不会自动从评测中剔除，以免通过删除困难帧改变结果。
