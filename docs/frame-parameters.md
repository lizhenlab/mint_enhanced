# 当前帧参数与逐帧分析

比较页画布上方的“帧参数”以及每个结果卡片的“逐帧分析”打开同一个面板。
面板默认关闭；打开时暂停，顶部提供独立“×”，也可用 Esc 关闭并返回原触发按钮。
输入法组合期间不会把 Esc 当作关闭指令。切换参数结果不自动改变候选算法；
所选结果尚未显示时，可明确点击“在画面中查看”，再用卡片“返回对比”恢复。

## 展示分层

- 卡片常驻两行左右手腕摘要，明确标出 X/Y/Z、cm 和有效/低存在性/跟踪/补全。
- 面板按手部、相机、质量、来源分组。手部细节默认折叠，避免默认铺满21行。
- 高级区显式加载当前帧原生参数；网格顶点可按20/50行分页，不在主画面铺开778行。
- 宽屏停靠在结果旁，普通窄屏使用抽屉/底部面板；播放条位于面板外。
- 关闭后恢复原比较布局，不改推理参数或历史结果。

## 字段与数值语义

| 类别 | 内容 | 边界 |
| --- | --- | --- |
| 手部 | 21点坐标、腕深度、双腕距离、腕速度、掌面几何方向、手指三点夹角 | 腕点为第0关节；几何派生量不是原生MANO旋转 |
| 相机 | K、fx/fy、cx/cy、从K推得的FOV、完整T_world_camera、位姿有效性 | T把相机列向量变换到世界；没有世界位姿时明确缺失 |
| 当前帧对比 | 对基准逐关节/关节均差/腕差、各自K下的投影均差 | 始终明确相机系、mm/px；无声明GT时只称算法差异 |
| 质量 | available、geometry_valid、presence、detected、tracked、filled、confidence、exists_2d/3d、pose_valid | false、0与缺失null分别保留；不同算法的分数不是统一准确率 |
| 来源 | 结果、模型/配置、后处理、工作网格、实现版本、耗时与资源、导入/复用/组件来源 | 复用或导入耗时不冒充从零模型推理 |
| 原始数据 | MINT、ACE、HaWoR的可证明逐帧原生字段及完整网格 | 保留原生维度、旋转表示、单位、坐标与来源，不制造统一欧拉角 |

相机坐标轴为 X右、Y下、Z前；标准几何文件单位米，坐标表以厘米显示。
Z是轴向深度。世界系使用当前公共源帧的相机原点；原生参数保持自己的原始坐标，
不会被显示原点变换悄悄改写。模型平移参数不直接等于解码后的腕点。

腕速度仅用相邻样本的相机系腕位置和真实时间戳；包含相机相对运动，不能称为
真实世界运动速度。跳帧到缓存块边界时补读真正相邻样本，不用显示抽样轨迹估算。
深度趋势仅作显示抽样，不参与速度或指标计算。手指屈曲代理为180°减三点内角，
掌面方向由关节点构造；两者都不是新的模型预测。

逐点差异与腕差保留原始尺度，不做隐含对齐。投影均差仅在21点双方均有正深度且
各自K有效时提供；它是当前帧的21点投影差异，不替代整段“指标分析”的完整统计。
基准是自己、参考缺失或几何无效时显示原因和“—”，不补假0。

## 可读取的原生参数

- MINT：每手109维编码（平移3、整体旋转6D、手指旋转90、形状10）、相机编码和存在性logit。
- ACE：按原始片段保留整体/手部旋转、形状、平移、直接预测点、存在性和原生像素网格K。
  重叠片段分别命名，明确是融合前原始值，可能不等于最终标准几何。
- HaWoR Full：世界系平移、整体/手姿、形状、有效性及相机旋转/平移/焦距。
- HaWoR Camera：只有原生JSON自带被冻结的帧表，或完整阶段标记同时冻结安全帧计划时可读取。
  旧产物只有pickle/joblib索引且无法证明帧映射时，原生字段显示不可用原因；标准几何仍可用。
- 导入参考和组件组合不冒充拥有本地原生MANO参数。

读取限定在该run的native目录，NPZ拒绝对象/pickle和越界/过大成员；JSON及响应规模有上限。
原生数组内存缓存按文件身份校验、最多64MiB；界面快照缓存最多8项。高级读取的容量限制
不会截断视频，也不会触发重新推理；超出时保留标准几何并说明原因。

## 按需加载与导出

高级加载是明确的暂停/当前帧快照动作，播放不会逐帧加载原生大数组。
切换帧、算法、左右手、坐标、比较或结果版本后，迟到回包不会盖回新选择。
新帧尚未手动加载时明确提示；返回已加载帧可命中有界缓存。

“导出JSON”明确读取当前帧可用的原生参数与网格，包含标准几何、来源、派生量及
派生公式边界。导出保留帧号、时间、run/sample、结果发布身份、公共原点和基准身份。
下载前若选择或基准发生变化则取消，不把不同上下文拼成一个文件。

API：`GET /api/comparison/runs/<run_id>/parameters?frame=<0起样本位置>&origin=<可选源帧>`。
既有`/frames`还补齐了`timestamps_s`、`T_world_camera`和`pose_valid`。

实现与验收：`parameters.py`、`parameter-panel.js`、`parameter-math.js`、
`parameter-summary.js`；相关CPU及前端测试位于`test_frame_parameters.py`和
`test_parameter_{math,panel,summary}.cjs`。本轮报告在
