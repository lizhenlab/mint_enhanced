## 执行流程

1. 读取本文件、当前 git 状态和最近的验收记录，确认已有改动的负责人；不要覆盖其他正在编辑的文件。
2. 按实际用户路径检查每个模块：进入、选择/读取、预检、提交、查看产物、离开、返回；记录具体触发条件和改前行为。
3. 优先修复来源/状态错误，其次收敛信息和高级配置，最后统一布局；不以改色、改字号替代逻辑修复。
4. 针对异步状态与协议边界增加有意义的回归，不为纯文字或简单样式重复编写镜像测试。
5. 运行适当检查，源码冻结后再做桌面和窄屏浏览器验收；若发现新错误，再有界修复和重跑相关检查。
6. 只有通过必要回归、真实页面与既有产物验证后，才在任务空闲时安全更新服务器；仅停止登记的 MINT 进程。
7. 保存截图、日志、提交、CI、部署与模型/历史文件一致性记录；确认 Mac 正式入口可访问，关闭临时预览及转发。
8. 主执行者逐项更新下方验收勾选；真正完成后才把会话中的 Goal 标记 complete，不因时间或预算停止而假定完成。

## 验收标准

- [x] 模块、子视图、对象深链接和浏览器前后导航一致；同一文档内切换不丢未提交草稿（诊断为独立文档，不自动复制表单），不自动运行任务。
