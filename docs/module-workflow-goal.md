## 事实模型

六个主模块为数据、比较、评测与质检、训练与模型、任务、工具。独立 `/diagnostics` 是 MINT 专业诊断工作区。模块是页面职责；后台服务、Run、执行任务和持久产物是另外的概念，不增加主模块数量。

常用闭环：输入 → 统一比较 → GT 评测/人工复核 → 原生伪标签生产或明确转换 → 可训练数据版本 → 训练/完整检查点 → 固定协议回归 → 模型登记/别名发布 → 显式选择模型的新比较。任务中心贯穿所有执行，工具与诊断按需参与。详见 [模块与功能地图](modules-and-flow.md)。

7. **发布**：GitHub CI 通过后，在任务空闲时仅重启登记的 MINT；保存备份、模型和历史身份、缓存恢复与 Mac 访问证据。
