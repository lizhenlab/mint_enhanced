# 数据、评测、训练与生产能力交付清单

基线：`2feac2f6ff51886f16d45cd52404c9eab0f46c49`。所有改动、环境、缓存和输出归属 MINT；外部 HaWoR、ACE 和 `/dataset` 原始数据只读。

| 工作包 | 交付与验收 | 状态 |
|---|---|---|
| 原生数据接入 | EgoDex / DexYCB / ARCTIC 正式适配、源目录清单、可恢复转换、受限存储、前端选择 | 已验收：5 个真实数据版本，另有取消 / 恢复样本 |
| 标定与固定评测 | 显式帧映射、ARCTIC 去畸变、内参同步、监督类型与官方划分检查、固定小集回归 | 已验收：3 套数据、12 次原生 GPU 运行；原始序列身份贯穿切片与伪标签 |
| 误差诊断 | 左/右手、存在性、二维/三维、深度与画面边界分组、可比较有效计数 | 已验收：API 与页面；真实遮挡标签缺失时不冒充遮挡评测 |
| 训练体验与验证 | 持久训练曲线、检查点对比、真实 MANO 与相机训练、验证 / 测试集回推 | 已验收：相机 20 步、MANO 10 步，均为双 GPU；目标模块变化审计通过 |
| 人工修正 | 二维关键点、可见性、左右手修正、审阅人和不可变父版本 | 已验收：真实图像编辑、版本历史与并发冲突；验收记录明确排除训练用途 |
| 性能试验 | 新进程推理、恢复阶段与完整结果查询分别标注，卡数对照、阶段瓶颈、数值门槛 | 已验收：实际峰值 1 / 2 / 4 / 8 卡，关节坐标差均为 0 |
| 数据生产 | 原生 MINT 后端的有来源伪标签生产和清洗、Ray CPU 编排、完整发布与恢复 | 已验收：完整 288 帧产物，显式允许后双 GPU 训练读回 5 步；原参考重建链仍单列依赖 |
| 多机执行 | 所属 SSH 启动 / 取消 / 失联清理、环境与数据核对、固定 world size | 已验收：单机双 GPU NCCL，拒绝重复物理主机；按要求保留跨机能力，不使用第二台服务器 |

验收包括 CPU/前端回归、隔离服务 API 与 UI、多数据集真实 GPU 运行、训练与检查点回推、取消恢复、源码和历史结果审计。短训练用于验证链路，不代表全量精度结论。

实际资源对照与操作说明见 [数据、回归、训练与生产工作流](native-data-research.md)。正式更新前要求 CI 通过、任务空闲、数据库与源码备份；只新增所属验证记录，历史数值产物保持原文件身份。
