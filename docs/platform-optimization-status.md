本次落实 2026-10-31 路线中的平台能力。代码、环境、工作进程和生成数据归属 MINT；HaWoR 与 ACE 安装保持只读。使用方法见 [统一任务、评测与训练闭环](platform-lifecycle.md)。

服务器回归通过 235 项 Python 测试（1 项本地资产检查排除）和 11 项前端测试。原生端到端样例包含 MINT、HaWoR Full、HaWoR Camera only、ACE K-free、ACE K-given 及显式 GT，6 份结果均覆盖完整 161 帧。训练检查 1369 个张量，其中仅相机头的 68 个张量更新，冻结参数无变化。这些结果验证功能和恢复能力，不证明模型精度提高。

验收输出保存在 MINT 的 `.deployment/platform-completion-20261031/.deployment/evidence/`，包括完整请求、结果清单、数值比较、双卡恢复、视频帧数、模型权重检查及外部目录审计。用于复核数据导出的自动验收记录明确标记为 fixture，不属于真实人工标注。

## 仍需真实外部输入的部分

- 原始 Ray 重建数据生产需要独立依赖、适配源码和 GeoCalib/MoGe/Mega-SAM 等资产；缺项会在预检列出。已有标签转换和相机伪标签导出已可独立运行。
- 生产训练需要正式数据、骨干与阶段初始化资产；验证配方是小尺寸相机训练样例，不能替代完整训练。
- 多机 NCCL、共享存储、云资源/镜像需要实际机器和账号配置后验收；当前交付配置校验与实验记录，不申请付费资源。
- 跨后端常驻模型服务尚未启用；当前复用限定在单个原生阶段，释放受资源压力、优先级和空闲时间约束。
