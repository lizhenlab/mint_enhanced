# 工具工作区

工具用于专项诊断、数据分析和已有几何结果的展示。日常多算法推理仍从“比较”创建；工具页不要求先运行所有分析，也不会因切换页签就自动启动任务。

## 三个入口

| 入口 | 用途 | 操作方式 |
|---|---|---|
| 工具目录 | 找到视频质量、相机内参 / FoV、数据集多样性、MINT 诊断或模型验证工具 | 查看用途和可用状态，进入对应工具后选择它需要的输入 |
| 生成展示视频 | 用已保存的手部几何生成 MuJoCo 场景或 Wuji Hand 运动学重定向视频 | 选择结果、工具和坐标，确认样本范围后显式提交 |
| 环境检查 | 检查推理、数据生产、训练与展示工具的环境条件 | 按需点击检查，展开详情查看缺少的依赖或资产 |

工具目录与生成表单分别展示，避免将“进入工具”误认为“立即计算”。可用状态说明当前后端和环境条件；具体任务还会核对选定输入、几何和参数。

## 各工具的作用与输入

- **视频质量**：检查视频输入的质量，帮助定位模糊、画面变化等数据问题。
- **相机内参 / FoV**：查看相机参数和视场角相关分析；不应把预测内参直接当作独立标定真值。
- **数据集多样性**：分析输入集合的数据分布，用于了解样本覆盖情况。
- **MINT 单算法诊断**：查看逐帧损失、研究参数和模型行为。它有独立的配置；需要将已保存预测显式加入比较，才会出现在统一比较记录中。
- **公开基准 / 检查点**：按专项工具要求的数据、模型与协议验证。它不等同于把当前视频直接作为官方 Benchmark。
- **配置与代码差异**：帮助比较研究配置和代码变化，不会自动修改正在运行的比较。

这些工具分别选择自己的输入与参数，不自动继承比较页或其他诊断页的表单。打开入口或检查环境不会自动提交推理、训练或云端评测。

## 生成展示视频

生成展示视频读取已有几何结果，不重新运行核心推理模型，也不覆盖原始预测。页面中的输入以所选结果和提交后保存的任务配置为准。

**MuJoCo 场景**用于展示已有手部网格，需要该结果具备 MANO 顶点。**Wuji Hand 重定向**把手部动作映射到机械手，用于运动学查看；这不代表接触、碰撞、抓取稳定性或动力学经过验证。

相机坐标下的展示不产生世界轨迹。原生世界坐标需要结果在选定范围内提供有效的世界相机位姿；缺少世界相机时应使用相机坐标。部分结果还可能缺少输出帧，任务会校验选定片段是否完整覆盖。

界面帧号从 1 开始，起止帧均包含；留空结束帧表示处理到样本末尾。默认完整片段，高级选项用于调整范围、视频宽度、存在性筛选和资源策略。共享资源策略与仅空闲策略决定等待条件，实际执行和等待原因在任务状态中查看。

提交后可查看进度、取消，或下载完成的视频及帧映射说明。失败、取消、中断或缓存释放的任务可**按原参数重新生成**，这是重新执行展示任务，并非从中断的视频帧继续渲染。更换当前结果不会改变已提交任务的来源和设置；查看任务时应同时核对来源与任务状态。

环境检查只说明运行条件，不能替代对输入、结果质量和输出视频的检查。当前比较指标在“比较”，逐帧复核在“评测与质检”，完整的后台执行记录在“任务”。
