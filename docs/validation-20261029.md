# 全面优化验收记录（2026-10-29）

本轮基于 `107ca368` 修复运行可靠性并优化资源调度。模型结构、权重、训练预处理、相机拼接与 UKF/RTS 公式保持原实现。

## 完成的改动

| 范围 | 结果 |
| --- | --- |
| 端口与服务 | 端口冲突明确报错；新增监督进程、所属子进程身份校验、有限退避重启和正常退出清理 |
| 模型生命周期 | 请求固定模型 generation；切换模型取消旧请求、后台关闭旧调度器；静态重载也会更新检查点身份 |
| 输入与结果缓存 | 按视频文件版本、视角、源帧索引、模型及参数隔离；替换同路径视频时旧请求返回 409 |
| GPU | 有界滚动队列、快卡持续领取窗口、按序拼接；保留最多 8 张卡的共享/退让策略 |
| 断点恢复 | 原始窗口预测原子保存、形状与有限值校验、损坏重算、跨进程恢复及网页任务记录 |
| 磁盘与内存 | 跨进程缓存配额、空间预留、LRU、安全租约；活动映射与窗口任务不会被回收 |
| 批量推理 | 独立选择完整/左眼/右眼；预解码、推理与渲染流水；NPZ 来源记录；完整结果跳过、残缺结果修复 |
| 视频导出 | 临时文件编码、检查退出状态及帧数、原子发布、失败清理与重试 |
| Benchmark | 显式 Shared / Idle / Dedicated，策略写入记录与缓存身份 |
| 参数与实现 | CLI、Viewer、Benchmark 共用推理内核；显式生产/Viewer 平滑预设，等价参数共用恢复身份 |
| 环境与诊断 | 独立训练/数据/QA 环境；公开资产 SHA-256 校验；训练输入检查、两阶段模型检查；CPU CI |

## 实际运行验证

- CPU 回归：**123 项通过**，包括此前六类故障的复现回归、取消、缓存租约、异构滚动队列、窗口恢复和服务崩溃恢复。
- 原片左眼：**10,428/10,428 帧**，1624×1232，源帧率约 36.0025 FPS，435 个窗口，源索引连续覆盖 0～10427。
- 输出预测数组全部有限；与优化前完整基线相比，相机、手部、存在性 logits 与 confidence 的最大绝对差均为 **0**。
- 输出 MP4 实际帧数为 10,428；滚动调度峰值同时运行 **8 张 GPU**。
- 本次包含首次 RGB 解码的端到端耗时为 **1018.20 秒**：解码 314.51 秒，加载模型 8.44 秒，推理 481.97 秒，视频渲染写盘 212.24 秒。峰值 RSS 39.71 GiB。
- 新进程以相同参数恢复：**435 个窗口全部复用、新计算 0 个窗口**，完整预测写出约 **17.09 秒**（未重新编码视频）。
- 网页“复用或恢复”已实际加载完整原片；左右手 21 点与相机数据正常，二维叠加视频为 1624×1232、约 289.65 秒，浏览器播放就绪且无控制台错误。
- 连续 API 测试：左右眼各 720 帧、重复请求、模型重载复用 30 个窗口、在途模型切换返回 409、同路径视频 12→18 帧替换、720 帧视频导出、两个视频批量执行/跳过/修复均通过。
- 带真值样例：450 帧，优化前后 Viewer 3D 几何完全一致。按同一可见性掩码和页面舍入后的相机系坐标计算，18,522 个关节样本的绝对 MPJPE 约 61.33 mm，腕部对齐 MPJPE 约 21.09 mm。该结果用于质量回归检查，不能代替论文评测；此样例未提供可直接用于页面训练 loss 的完整字段。

此前 617.24 秒的完整基线使用了已有 RGB 缓存，和本轮首次解码的 1018.20 秒不具备直接可比性。共享 GPU 负载也会变化，不据此宣称固定提速倍数。
