# 工作台入口与操作衔接

入口 `/compare`，Mac 已有转发地址为 `http://127.0.0.1:18011/compare`。

| 一级入口 | 二级功能与常用操作 |
| --- | --- |
| 数据 | 视频与 LeRobot 选择、开源数据原生接入、数据与结果目录、批量比较 |
| 比较 | 按输入分组的历史记录、同步 2D/3D、指标、结果管理与相机组合、报告与视频导出 |
| 评测与质检 | 当前比较指标、数据集评测、逐帧质检、检查点回归/性能、公开基准 |
| 训练与模型 | 数据准备、训练、曲线与完整检查点、原生伪标签生产、模型版本与发布 |
| 任务 | 实际执行任务、阶段、等待原因、资源、日志、取消与恢复 |
| 工具 | 可用状态、环境检查、专项分析、仿真与重定向、MINT 单算法诊断 |

模块采用持续工作区，切换后保留表单与滚动位置。URL 的 `hub`/`section` 可直达模块，兼容既有比较、工作流、试验与批次链接；浏览器返回可切回上一模块。新建比较仍为明确提交的配置窗口。

## 比较与单算法诊断的关系

多算法比较是日常工作入口，MINT 单算法诊断是“工具”中的专业模块，共用 MINT 推理实现。只运行 MINT 也可在新建比较时仅勾选 MINT。诊断页用于逐帧损失、平滑、手形和内参等研究检查；两处表单和当前结果状态各自保存，诊断结果需显式“将已有结果加入比较”才进入统一对照，导入不重复网络推理。

诊断页按输入与运行、实际结果、专项工具排列，主运行按钮在输入区首屏，高级参数默认折叠，返回入口指向比较工作区。

## 常用路径

1. 视频/LeRobot：新建比较 → 选择输入 → 配置帧协议、算法、资源 → 查看提交协议概览 → 输入预检 → 开始比较。
2. 开源数据：新建比较中的“开源数据集/GT” → 原生数据目录、官方划分和序列 → 准备数据版本 → 同输入比较；训练格式完成后可直接转到训练。
3. 结果：比较 → 联动查看 → 当前比较指标/逐帧质检 → 导出。指标没有声明 GT 时只表示算法差异。
4. 模型迭代：训练数据版本 → 训练任务 → 完整检查点 → 固定集回归 → 模型登记与发布门槛。命名选择器优先，ID、路径和 JSON 保留在高级配置。
5. 数据生产：选择已有比较及完整原生 MINT 结果 → 原生后端伪标签预检与生产 → 发布伪标签版本。伪标签训练仍需显式允许。

## 状态与协议

- 当前 GPU 与允许上限分开；SLAM 等时序阶段不会暗示能使用全部 GPU。
- 卡片与任务中心共用阶段说明。ETA 只在索引状态、阶段和计数匹配时展示，且仅代表当前阶段；无法估算时明确说明。
- 参考研究链（MegaSAM/MoGe/GeoCalib 等）与原生 MINT 伪标签生产分开；缺依赖的参考链会显示预检原因并阻止提交。
- 工具页区分适配器是否实现、当前模型能否输出该指标，以及云端配置是否完整。多机配置可校验保存，跨机器执行入口保留在 CLI；当前只使用现有服务器。
- 输入源索引从 0 开始，播放与人工复核帧从 1 开始；结束复核帧包含在区间内。最多帧数留空仍处理完整视频。
- MINT 单算法诊断的新默认平滑与比较平台 Production 预设一致；显式选择或恢复的历史预设继续保留。

## 标注与记录

选中点高亮，画布支持方向键微调、Shift 加大步长、`[`/`]` 切关节。上一/下一问题片段需先分析质检候选。未提交修改即时保存为本机草稿；恢复时核对服务器父版本、源图像和结果身份，不覆盖服务器的新版本。保存期间继续修改的内容保留为下一版草稿。

二维修正不会生成真实三维或 MANO GT。接口验收标记收在开发者选项中。历史比较默认收起明确的系统/验收、仅参考记录，搜索和“全部记录”仍可找到，当前选中的记录始终保留。
